# 💌 dearworld. — a love letter to everywhere

*A little world of big dreams, beautiful places, and unforgettable journeys.* 🌍🎀

## 🌷 About the Project

**dearworld.** is a cinematic travel discovery website designed to make exploring the world feel a little more personal, dreamy, and exciting.

The idea is simple: everyone deserves to find their kind of somewhere.

Whether you're dreaming of peaceful beaches, mountain mornings, city adventures, a romantic getaway, or even a business trip, dearworld aims to help you discover destinations that match your interests, budget, and available time.

This is a personal web development project, currently focused on building a beautiful and immersive frontend experience.

## ✨ Features

- 🌍 **Cinematic 3D Earth** — An interactive visual experience built with Three.js.
- 💌 **Dreamy Travel-Inspired Design** — A soft, modern travel aesthetic with immersive visuals.
- 🧳 **Travel Discovery Concept** — Destination ideas based on different travel moods and interests.
- 💸 **Budget-Friendly Travel Concept** — Designed around helping travelers explore within their budgets.
- ✈️ **Leisure & Business Travel** — A concept for both personal adventures and work-related trips.
- 🌷 **Smooth Scrolling & Animations** — A polished browsing experience with scroll-based effects.
- 📱 **Responsive Layout** — Designed to adapt across different screen sizes.

## 🚀 How to Run

**Option 1 — VS Code Live Server**

1. Open the project folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

**Option 2 — Using Terminal**

Open Terminal inside the project folder and run:

```bash
python3 -m http.server 5500
```

Then open:

http://localhost:5500

**Note:** An internet connection is required to load CDN libraries and remotely hosted 3D assets.
